# context_wrangler history

The version record that used to open the README.

> Written while the repo was still local. Statements below that a CI workflow has never executed or that nothing is pushed were true on 2026-11-21 and are kept as history; the live state is the badge in the README.

## Status as of v0.5

v0.1 through v0.5 are built; the roadmap shipped. No CI workflow has executed yet, and nothing is pushed. v0.1: ingest, structure-aware chunking, FTS5 BM25, search CLI with cited spans. v0.2: sqlite-vec embeddings, hybrid fusion with RRF, the seeded corpus generator with machine-checkable answer keys, and the eval harness that published the baseline tables below. v0.3: the token-budget context assembler, the grounded answering CLI, and the refusal gate enforced in code. v0.4: OpenRouter providers with exact per-call cost metering, the cost/quality frontier table across three model tiers, fixed-seed multi-run answer evals that publish measured instability, the rerank stage behind a flag with its latency and cost documented, and README tables that regenerate between marker pairs instead of rotting. v0.5: the two extraction regimes. Optional OCR (system pdftoppm + tesseract, per page, and only where a page's text layer is thin) and coordinate-aware table reflow, each stamped into index meta so one index can never mix extraction regimes. The corpus grew a settlement table drawn the way real table writers draw, column-major, which breaks label-value pairing in naive extraction and is what --tables repairs; table questions grade on the reflowed row string, at chunk level, where document-level recall cannot hide the damage. And the whole corpus now has a scanned image-only twin that scores against its text original, so the price of OCR is a published number instead of a vibe. The proof: 164 tests pass on Python 3.14.9 (2026-11-21), `cw verify` byte-checks every indexed span including the OCR'd ones, `python -m evals --selftest` proves the metric functions, the API tiers are verified live against a metered OpenRouter account, and every published table below was produced by a command printed next to it.
